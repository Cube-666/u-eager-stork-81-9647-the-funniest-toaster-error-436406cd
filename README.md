The funniest error message a kitchen toaster would show its owner, in 120 characters or fewer: a deadpan fault code with a grudge. `main.ts` writes the single line to `/output/entry.txt`.

> E02: No bread detected. The toaster will remember this.

Why this line: it reads like a real appliance error — an E-code, a plain statement of the fault — and the joke arrives from somewhere the obvious toaster puns never go. No toast pun, no crumbs, no "404: bread not found": the toaster itself holds the grudge, in one clear deadpan voice, and the whole joke lands on a single read. At 55 characters it is as short as it can be rather than as long as it may be.

## Run it

```sh
node main.ts
```
